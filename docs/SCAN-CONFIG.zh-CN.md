# 可重复扫描与复核记录

这些功能位于 `main` 开发源码，已发布的 v0.3.0 EXE 尚未包含。

## 项目配置

在被扫描项目根目录放置 `.xss-audit.toml`，桌面和 CLI 会自动读取。没有默认配置文件时使用原有预算。可从仓库中的 `.xss-audit.example.toml` 开始修改。

```toml
[scan]
include = ["src/**/*.js", "src/**/*.ts", "server/**/*.py"]
exclude = ["src/generated/**", "reports/**"]
max_file_bytes = 1048576
max_total_bytes = 104857600
max_files = 10000
max_matches = 10000
strict = true
```

路径使用 `/` 并从项目根目录匹配。`*` 不跨目录，`**` 可匹配零层或多层目录；`src/**/*.js` 同时包含 `src/app.js` 和更深层文件。`include=[]` 表示所有支持格式。排除优先于包含，排除目录也会排除其子目录。原有依赖、构建产物与链接排除继续生效。配置不会执行项目代码，也不加载自定义 Python。未知键、无效 TOML 和非法预算会报错。

预算可在固定上界内调高：单文件 16 MiB、总读取 512 MiB、50,000 个文件、50,000 条匹配。配置文件限 64 KiB；单条 glob 限 512 字符和 64 个路径段。

```powershell
python -m xss_audit D:\project --config audit-settings.toml --lang zh-CN --format json -o audit.json
```

显式指定的相对配置路径从被扫描项目根目录解析；显式文件不存在时报错。报告和桌面“扫描范围与解析说明”包含最终生效配置。

## 覆盖状态与退出码

报告逐文件区分：`ast_and_patterns`（AST 与规则）、`patterns_only`（仅规则）、`ast_incomplete`（AST 不完整）、`read_failed`（读取失败）、`binary_source`（二进制／非 UTF-8）和 `file_budget`（文件超过预算）。主动排除项继续列在跳过清单中。仅支持规则搜索的语言会明确标注，本身不会使扫描失败。

严格模式默认开启。支持的源码无法读取、超过单文件预算或包含二进制／非 UTF-8 内容时，扫描记为不完整；没有读取到任何支持的源码也记为不完整。CLI 保留报告并返回 2。解析失败、取消和总预算中断继续属于不完整。SARIF `executionSuccessful` 与各格式报告使用一致覆盖状态。

需要有意接受部分结果时，可配置 `strict=false` 或传 `--allow-partial`。覆盖缺口仍保留在报告中，SARIF 仍标记执行不完整；该选项只改变 CLI 对完整性的退出码政策，`--fail-on-match` 有匹配时仍返回 1。

新导出的 JSON/HTML 带报告标记，下一轮扫描会识别并跳过。业务 JSON 继续支持，即使名为 `xss-audit-report.json`，没有报告标记也不会仅因文件名被排除。旧版无标记报告可通过项目 glob 排除。

## 复核记录

相同文本的不同命中实例现在使用独立身份。复核决定同时保存整个源文件的证据摘要；文件中任意内容变化后会保守地要求重新复核，包括注释和格式变化。当前尚不跟踪其他文件的依赖变化。切回完全相同的旧源码快照，可以恢复对应旧决定。

保存时合并当前窗口修改的决定，其他快照或部分扫描未出现的记录仍会保留。多个窗口分别修改不同结果时，不会用本窗口未改动的旧行覆盖另一窗口的新判断。清除标记只清除当前证据版本。记录文件仍限 2 MiB；超过上限会拒绝保存并保留原文件。

旧 v1 记录仅在当前扫描中旧指纹唯一时恢复，保存时升级证据元数据；有歧义的重复命中需要重新复核。旧记录尚未升级时，仍只有旧版附近代码校验的边界。

桌面新增待确认、确认风险、误报、已修复等状态筛选。桌面导出继续包含完整扫描；类别、优先级、状态和搜索只改变视图。

## 新增分析模型

HTML 流新增 `srcdoc`，以及工厂未被局部覆盖的直接 `$(...).html(value)`／`jQuery(...).html(value)`。普通对象 `.html()` 和 jQuery `.text()` 不按 HTML 写入处理；暂不推断任意 jQuery 别名、保存到变量的接收者或插件链。

Python 支持对已建模调用进行静态 `import`／`from import` 别名解析，并遍历 `with`／`async with` 的上下文表达式。局部重绑定会影响导入身份。JavaScript 中局部同名声明及已建模净化器覆盖不再自动抑制 HTML 证据。分析仍有边界，没有完整跨文件／跨函数能力。
